## Question

On the new model, can a model-specific presentation of the mind's working frame, chosen before any skill is grown, plus a skill regrown from the mind's verified experience inside that presentation, beat the raw model with a separate contribution from both presentation and skill?

Several candidate presentations of the same stored mind were compared. The selected presentation and the candidates remain private.

## Protocol (conceptual)

1. Compare several presentations of the same stored mind without a skill on fresh development tasks.
2. Apply a frozen rule and publish the selected presentation's hash before the test.
3. Let the mind practise inside the selected presentation and the old frame. Keep only verified successes and regrow one small adapter from each.
4. Accept a skill only if it beats no skill in a separate quarantine check by the pre-registered rule.
5. Compare the raw model, both frames and their skills on fresh final tasks. Check the combined artifact on unseen families, then check general capability, identity, selection-rule compliance and the stored mind.

Task construction, presentation details, adapter details, runtime settings, decision cutoffs and other private implementation details are withheld.

## Deviations from the pre-registration

Four amendments were published as hash commitments before the code each fixed ran:

1. A token counter crashed after all development replies were recorded. Replaying those recorded replies produced 0 verdict differences.
2. A slow request ended a practice run while its replies existed only in memory. The run was aborted before any result was seen. Replies are now checkpointed and the work is split into more sessions.
3. A training path error stopped training before it began.
4. A final-test session ran out of time before any final result was written or read. Each part is now saved when it finishes, and the final test was rerun fresh.

One report-only comparison failed because EXP-0048's skill was never loaded. Its requests scored zero. It entered neither selection nor any gate. The omitted label prefix is also disclosed above.

The pre-registration, first amendment and selection proofs confirmed after their governed work began. The second, third and fourth amendments confirmed before their work started.

## What this does not show

- **More than one training run per presentation.** There was one trained skill for each presentation.
- **Transfer beyond this setting.** This is one model and the registered task families. The unseen test has 200 tasks over four families, so it is coarse.
- **That either skill was harmful in quarantine.** Both were refused because they were not shown to help there.
- **A supported migration result.** A presentation can be re-chosen for a new model, but a skill regrown inside it was not shown to help and hurt transfer.

## Reading

Re-presenting the same stored mind turned a 10.7-point cost into a 7.9-point gain on familiar task families. The presentation is most of the effect. The regrown skill added little on familiar families and was not accepted in quarantine.

The gain did not hold on unseen families. Most of the loss came with the skill: the new presentation scored 152 there, and the combined artifact scored 141.

The migration claim is not supported. The proposed next question, pending owner decision, is why the regrown skill hurt unseen families and was refused in quarantine while the presentation alone helped on familiar families. Options include regrowing from more varied experience, testing more than one training run per presentation, and checking unseen-family transfer before any skill is accepted.

EXP-0048 is not a full migration, and this result does not change its supported claim: after migration, the same persistent mind accumulated verified experience on the new cortex and regrew a cortex-native neural skill that improved performance beyond the raw cortex, while the persistent working frame still imposed a measurable cost.
