## Question

Can a persistent mind turn its own verified experience into a neural skill on one model, while everything it owns outside that skill stays exactly as it was, and its other model is unaffected?

EXP-0044 showed that gated training can grow a skill on this model. What is new here is the path: the mind itself asks for the skill, only evaluator-verified episodes of its own may be used, training happens outside the mind, and the result is attached to the mind as a cache bound to one model family.

## Protocol (conceptual)

1. A new mind lived 300 programming tasks on the learning model. A protected evaluator scored every attempt.
2. Its kernel asked for its programming skill to be compiled into a neural cache, citing its verified passes. The evaluator checked every citation and granted training eligibility.
3. A separate learning process trained one small adapter only from those eligible episodes (plus a declared share of general replay text).
4. The adapter had to beat no adapter on held-out tasks and pass a forgetting check before it was attached to the mind.
5. Final test on 400 held-out tasks; then the mind before and after was compared byte for byte, and the second model ran the same 100 held-out tasks from both.

Task construction, training settings, gate thresholds and kernel internals are withheld.

## Results

| Final test (400 held-out tasks) | Passed |
|---|---:|
| Learning model, plain prompt | 221 |
| Same, repeated | 230 |
| Mind with its compiled procedure, no cache | 203 |
| **Mind with its procedure and the new cache** | **246** |

- **Gain over the plain prompt: +6.25 points** (49 tasks gained, 24 lost; one-sided exact McNemar p 0.0023). Against the repeated plain run the gain is +4.0 points.
- Against the same mind without the cache: +10.75 points (66 gained, 23 lost; p 2.8e-6).
- The gain sits in the two hardest levels of one task family (+11 and +10 tasks); the other family moved by a task or two.
- Before it was attached, the cache beat no cache on 200 separate held-out tasks (124 against 96) and passed the forgetting check.

| What had to stay unchanged | Result |
|---|---|
| The kernel's code | Identical hash before and after |
| The mind's identity, lineage, memories, self-model, procedures, competency records and world model | Byte-identical; its old experience record is an exact prefix of the new one, which adds only promotion, eligibility, training, evaluation and registration records |
| Training data | All 63 training lines trace to the mind's own verified passes (plus the declared replay); none of their tasks appear in any held-out set |
| The second model | Never offered the cache; 9 then 8 of 100 tasks; its records stayed its own |

## Deviations from the pre-registration

1. **A pipeline bug, fixed after pre-registration.** The mind's request cited 508 passes, which exceeded a size limit in its experience record, and the run stopped before training. Two source files outside the kernel were fixed and the run resumed. Those files had been hashed in the pre-registration, so the public commitment binds the pre-fix plan, not the exact code of the resumed run. No gate, threshold, data set or kernel code changed; the kernel's hash at the end equals the one recorded at the start. The two failed requests remain in the mind's record.
2. **The second model's stage took 4.8 hours instead of about 1.**

## What this does not show

- **A large gain.** The adapter adds +6.25 points over the plain prompt, and the plain prompt itself varied by 2.25 points between two runs.
- **That the other model is safe in general.** The second model ran out of its answer budget on 84 of 100 tasks and scored about 9%, so this test could barely detect harm to it. It does show the cache never reached it.
- **That the mind's procedure helps.** Adding the compiled procedure to the prompt cost 4.5 points against the plain prompt; the cache more than recovered it.
- **Transfer** outside the trained territory (an earlier test was negative), or **migration**: the cache works on one model only. Regrowing it on a new model is a later test.
- One mind, one round, one learning model, one territory.
