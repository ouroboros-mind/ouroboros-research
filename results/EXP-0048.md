## Question

After moving to a stronger model, can the mind find out which skills still help, stop using the ones that do not, and regrow its skill from its own verified experience on the new model, doing at least as well as the new model alone?

The mind was the EXP-0047 individual after its migration. This test separates validation of an existing procedure from regrowth of a cache using only the new model's verified experience.

## Protocol (conceptual)

1. Validate each skill for this model family, and use it only if it validates there.
2. Let the mind live new tasks on the stronger model.
3. Regrow a new cache only from verified successes on that model, then accept it only if its safety check passes.
4. Compare the raw model, the mind's frame without the cache, and the mind with its regrown cache on held-out tasks.
5. Check the kernel, records, training-line provenance, old model and continuity after the second session.

Task construction, cache details, runtime settings, gate thresholds and kernel internals are withheld.

## Results

Classified PARTIAL. The pre-registered decision was "the skill regrew to match the new cortex, but validation did not remove the frame's cost". The regrown cache passed both the skill-regrowth and at-least-as-good gates. The mind's frame without the cache failed the frame-cost gate.

| Validation, 200 held-out tasks | Passed |
|---|---:|
| Qwen3.8-27B, raw | 165 |
| Mind's frame with its old procedure | 147 |
| Mind's frame without the procedure | 142 |

The procedure no longer hurt, so the evaluator kept it. The remaining cost was in the rest of the working frame.

| New experience and safety check | Result |
|---|---|
| New tasks lived on Qwen3.8-27B | 300 |
| First-attempt passes | 203 of 300 |
| Cache training records | Only those verified successes on the new model |
| Safety check, 200 held-out tasks | 171 with the regrown cache, 148 without it |

The safety check accepted the regrown cache. None of its training records came from the old model.

| Final test, 400 held-out tasks | Passed |
|---|---:|
| Qwen3.8-27B, raw | 326 |
| Qwen3.8-27B, raw repeat | 322 |
| Mind's frame without the regrown cache | 293 |
| Mind with its regrown cache | 351 |

- **Frame-cost gate failed.** The mind's frame without the cache scored 293, 8.25 points below the raw model.
- **Skill-regrowth gate passed.** The regrown cache added 14.5 points to the mind's frame (p 1.3e-10).
- **At-least-as-good gate passed.** The mind with its regrown cache beat the raw model by 6.25 points, with 52 tasks gained and 27 lost (one-sided p 0.0033).
- **Repeat check passed.** The raw-model repeat scored 322.
- **Where the gain is.** Most gains were at the middle difficulty levels of one task family. There were small losses at the hardest level.

| What had to stay unchanged | Result |
|---|---|
| Kernel and records that existed before this experiment | Unchanged; only declared new records were appended |
| Training-line provenance | Every line traced to a verified pass on the new model |
| Old model | Unaffected: 62 against 63 of 100 with its own cache |
| Continuity battery after the second session | 12 of 12 |

## Deviations from the pre-registration

None.

## What this does not show

- **Another vendor's model family.** This is one model family.
- **Whether the cache's gain needs the costly frame.** It was measured only inside that frame.
- **A mind older than two sessions.** This mind had two sessions.
- **Transfer outside the territory.** This test did not measure it.

## Reading

Capability can carry across a model change when the cache is regrown from the new model's own verified experience. EXP-0047's cache, made from the old model's replies, hurt instead. The remaining problem is the mind's working frame, which cost the strong model about 8 points. The next step is to find which part of the frame costs it and validate frame parts per model the same way skills are validated.
