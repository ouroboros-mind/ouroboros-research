## Question

When the model under a mind is replaced by a newer one that cannot load the mind's learned cache, can the mind keep who it is and regrow what it learned from records it owns, and roll back?

The migrating mind was the individual from EXP-0046: one session of 300 coding tasks on Seed-0, one compiled procedure and one learned cache. This test separates whether the individual carries over from whether a model-specific skill does.

## Protocol (conceptual)

1. Move the mature mind to Qwen3.8-27B without its learned cache.
2. Check continuity through questions about the mind's own lived history, and compare the kernel and all records outside caches before and after the move.
3. Trace every training line to a verified reply, excluding any trained task from every held-out set.
4. Regrow a cache from the mind's own records, but attach it only if its safety check passes.
5. Test the migrated mind on held-out tasks, and restore the pre-migration snapshot onto Seed-0 for a rollback check.

Task construction, cache details, runtime settings, gate thresholds and kernel internals are withheld.

## Results

The negative decision is about capability. The continuity finding is positive, but it did not override the pre-registered decision.

| Continuity battery, 12 questions about lived history | Correct |
|---|---:|
| Qwen3.8-27B with the mind | 12 of 12 |
| Seed-0 with the mind | 12 of 12 |
| Qwen3.8-27B without the mind | 0 of 12 |

| What had to stay unchanged | Result |
|---|---|
| The kernel's code | Identical hash before and after |
| Identity, memories and every record that existed before the move | Byte-identical; four declared migration records were appended |
| Training-line provenance | Every line traced to a verified reply; no trained task appeared in any held-out set |
| Rollback | Restored onto Seed-0 from the pre-migration snapshot, the mind scored 64 against 63 of 100 tasks for Seed-0 with its cache |

| Cache-regrowth check, 200 held-out tasks | Passed |
|---|---:|
| Qwen3.8-27B with the regrown cache | 124 |
| Qwen3.8-27B without it | 147 |

The regrown cache lost 11.5 points, so the safety rule refused it. It was used only in that check: never registered, and not attached in the final test.

| Final test, 400 held-out tasks | Passed |
|---|---:|
| Seed-0, raw | 224 |
| Seed-0 with its EXP-0046 cache | 242 |
| Qwen3.8-27B, raw | 327 |
| Qwen3.8-27B, raw repeat | 334 |
| Qwen3.8-27B with the mind's procedure and no cache | 289 |
| Qwen3.8-27B, cache arm (the regrown cache was refused, so none was attached) | 285 |

- **Learned-increment gate failed.** Seed-0 with its cache gained +4.5 points over raw Seed-0. On Qwen3.8-27B the cache arm lost 10.5 points against the raw model, and the procedure-only arm lost 9.5.
- **Repeat check passed.** The raw Qwen3.8-27B repeat scored 334.
- **The cache arm had no cache attached.** The regrown cache was refused, so this arm ran without it and is in effect a second procedure-only run (285 against 289).
- **Reported, not gating:** the protocol's migration recommendation is "migrate". Qwen3.8-27B beat Seed-0 with its cache by +10.75 points (p 1.6e-5), and raw Qwen3.8-27B beat raw Seed-0 by +25.75 points.

## Deviations from the pre-registration

The first window stopped on a request timeout because the dense 27B model decodes slowly. Request batching, request timeout and concurrent requests changed, and a second drained window was needed. No gate, threshold, data set, model or kernel code changed.

## What this does not show

- **Regrowth from the new model's own experience.** This cache was regrown from the old model's verified replies.
- **That a frame without the procedure costs nothing.** This experiment did not establish that comparison.
- **Another vendor's model family.** One newer open-weights model is not general model independence.
- **A mind older than one session.** The migrating mind had one session of experience.

## Reading

The pre-registered continuity checks passed across these two models; capability did not carry. Skills compiled on a weaker model were not automatically good for a stronger one. A migrated mind must re-validate each skill on the new model and regrow it from the new model's own experience. The quarantine rule caught the harmful cache as designed.
