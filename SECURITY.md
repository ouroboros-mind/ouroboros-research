# Security

This repository contains documentation and images only. It contains no Ouroboros code, models or data.

## Reporting a vulnerability

Please report security problems related to this repository or the Ouroboros project privately, through GitHub's private vulnerability reporting ("Report a vulnerability" under this repository's Security tab). Please do not open a public issue.

## Research safety

Ouroboros research is designed so that the learning system does not promote its own changes. Evaluation material and promotion rules are kept outside the learning system, model-written code is designed to run only in an isolated sandbox, and promotion to a new generation is a recorded human decision. These are design properties of a private system that has not been independently audited.

If you see a claim in this repository that would be unsafe if true, or a result that suggests these safeguards failed, please raise it through the private channel above.
