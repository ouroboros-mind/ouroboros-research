# Odds log

We publish our own estimate of whether this project's central question ends in a clear yes, and why the number moves after each result. The number is subjective. It is not a statistic, and it is not evidence that the project works. It is published so the project can be held to its own predictions.

Estimates are published by the project. The author reviews and approves each number before it is published.

## What the number means

Our estimate, in percent, that the central research question in [RESEARCH_QUESTION.md](RESEARCH_QUESTION.md) is eventually answered yes, with the five proofs passing in their pre-registered forms.

## Rules

1. From 2026-10-22 on, every update to the running estimate carries a one-line reason. The numbers in earlier rows are never edited, and any later change to the wording of an earlier reason is announced on this page.
2. From EXP-0048 on, each experiment's own estimate of passing its pre-registered rule is added to this page before the run starts. GitHub records when each change arrives. None has been added yet.
3. After each result from EXP-0048 on, this page says whether that experiment's estimate was above or below what happened.
4. Every reason is checked against the [publication policy](docs/publication-policy.md) before it is published.

## Reading the table

- **Date** is the date of the result or step the estimate follows. Reconstructed estimates carry that date but were assigned later. It is not the experiment's pre-registration date: that date is in [EXPERIMENTS.md](EXPERIMENTS.md) and can differ by a day.
- **Reconstructed** rows (through EXP-0043) were assigned in hindsight, before 2026-10-22, when this log was first assembled, not on the day of each result. **Recorded at the time** rows are author-reported and cannot be verified from this repository.
- **Restatement.** Every reason on this page was restated for publication on 2026-10-22, including the rows marked "recorded at the time", to remove internal labels and tighten wording. The restated text is not the text as first written. The numbers were not changed. 23 early rows have no recorded reason and say so.
- Labels come from the [experiment ledger](EXPERIMENTS.md). Design and build steps between experiments are not ledger entries.
